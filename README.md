# WhispBot · made by Szymbot

Transkrypcja (Whisper, lokalnie), napisy SRT i cięcie ciszy dla Premiere Pro (Windows).

## Instalacja

1. Wejdź w [najnowszą wersję](../../releases/latest) i pobierz **WhispBot-Instalator.bat**.
2. Zamknij Premiere Pro i uruchom pobrany plik. Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij „Więcej informacji”, a potem „Uruchom mimo to”.
3. Po instalacji: Premiere Pro, potem Window, UXP Plugins, WhispBot.

Aktualizacje pojawiają się w panelu jako przycisk „Aktualizuj”.

To repozytorium zawiera tylko paczki instalacyjne.
